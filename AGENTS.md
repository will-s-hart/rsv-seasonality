# Agent instructions

This is a Julia research project on climate-dependent RSV transmission with Will and Torkel Loman.

- Start with [README.md](README.md) and [the analysis plan](notes/analysis-plan.md), then inspect relevant code and recent changes to establish what is already done. Follow explicit user directions over the default workflow below.
- With a minimal prompt (e.g. “continue”), advance the next unfinished, unblocked task in the analysis plan. If the prompt or session identifies Will or Torkel, follow that person's responsibilities; otherwise choose the earliest unmet prerequisite that enables progress. State the task chosen and carry it through to a concrete, reviewable deliverable rather than stopping at a plan. Ask only when a material ambiguity or dependency prevents useful progress.
- Will leads epidemiological data/observation audits, renewal dynamics, and inference; Torkel leads climate processing, neural responses, differentiation, and optimization. Use the plan's current immediate actions and completion criteria rather than treating this summary as a fixed task list. Do not assume planned work is complete or duplicate existing work.
- Keep scientific design and interpretation in [modelling methodology](notes/modelling-methodology.md), acquisition details in [data sources](notes/data-sources.md), and evidence in [the literature review](notes/literature-review.md). Follow [data conventions](data/README.md) and [result/run conventions](results/README.md); keep credentials, raw/processed datasets, and generated results out of Git.
- Implement reusable Julia components in `src/` and reproducible entry points in `scripts/`. Run `julia --startup-file=no --project=. scripts/check_setup.jl` after code/environment changes and add task-appropriate validation (including recovery/gradient checks for numerical methods). Report what was checked and any limitations; distinguish synthetic results from empirical findings.
- After substantive work, update the analysis plan with completed work, remaining blockers, and the next concrete action for the relevant owner; record methodological decisions in the linked notes. Do not mark a stage complete without its stated deliverables.
- Agents can and should update this file as the project develops. Keep it concise, correct stale guidance, and put specifics in the relevant Markdown documents rather than duplicating them here. Keep `CLAUDE.md` as the single line `@AGENTS.md`.
