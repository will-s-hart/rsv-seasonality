# Aggregate natality sources, 2013–2019

The [source manifest](../data/natality-sources.toml) records the official releases, scope, SHA-256 pins and national controls for calendar-month live births. The department audit on 24 November 2026 verified 3,948 Japan prefecture-months and 4,284 US state/DC-months at the reconciliation levels below. The earlier Cloud proxy returned 403. These checks support natality input acquisition and reconciliation. Panel assembly, territory coverage and modelling decisions remain open.

## Japan

Volume 2 Table 2 has one file per birth year. The 2013–2017 files are titled `出生数，性・出生月・市部－郡部（全国）・都道府県（２１大都市再掲）別` (births by sex, birth month, nationwide city/county and prefecture, with 21 major cities reprinted). The 2018–2019 title is `出生数，市部－郡部－都道府県（特別区－指定都市再掲）・出生月・性別` (births by city/county, prefecture, birth month and sex, with special wards and designated cities reprinted). Each CP932 CSV has a published annual total and January–December counts in total/male/female triplets. There is no age dimension. The final main tables cover Japanese vital events in Japan. MHLW separately tabulates foreign nationals in Japan, Japanese nationals abroad, and prior-year events. The address used to classify births by prefecture is the child's. The wider resident-population denominator may include other nationalities. [MHLW final survey scope and symbols](https://www.mhlw.go.jp/toukei/saikin/hw/jinkou/kakutei19/dl/01_cho.pdf), [MHLW 2017 report Table 3-3-1, note 1](https://www.mhlw.go.jp/toukei/saikin/hw/jinkou/houkoku17/dl/03.pdf).

## United States and territories

The standard CDC WONDER Natality 2007–2024 request form (D66) returned two aggregate TSV results on 24 November 2026. Select 2013–2019, all locations and characteristics, and births only. Group the state/DC request by State, Year, Month and the national request by Year, Month. Turn on Show Totals and leave Show Zero Values and Show Suppressed Values off. The state and national queries provide their own annual subtotals. By-residence tabulations cover live births occurring in the 50 states and DC to residents of those jurisdictions and assign state by the mother's legal residence. Each count represents liveborn infants across all characteristics. The audit retained and checksummed the native TSV bodies with their query notes using the eLinks Save as command. The normalized rows match those from the earlier Lynx source-view captures. [WONDER collection](https://wonder.cdc.gov/natality.html), [request form](https://wonder.cdc.gov/natality-current.html), [documentation and residence definition](https://wonder.cdc.gov/wonder/help/natality.html), [data-use terms](https://wonder.cdc.gov/datause.html).

Use the first count column of the NCHS final report by place of residence, labelled All races (2013–2015) or All races and origins (2016–2019). For the independent monthly controls use the observed Number column of Internet Table I-2. The table also reports rates and seasonal adjustments. The source manifest pins the PDFs and their URLs. Stacks serves DS2 for 2013, 2014 and 2019. The expected Stacks DS2 paths for 2015–2018 returned HTTP 404, and the supplements linked from the final reports were available directly from NCHS.

## Stage and validate locally

Use an ignored local data directory or an equivalent private directory outside the checkout. Preserve original bytes where available, plus an acquisition receipt with the official URLs, source version, retrieval time in UTC, filename, byte size, SHA-256, scope and reuse terms. The audit's original e-Stat CSVs, NCHS PDFs and two dated WONDER TSVs are pinned in the manifest. A new WONDER export can have a different SHA-256 because the provider includes the query timestamp. The earlier browser captures and independent transcriptions have local receipt hashes. [e-Stat reuse terms](https://www.e-stat.go.jp/en/terms-of-use), [NCHS report rights](https://stacks.cdc.gov/view/cdc/231899), [WONDER data-use terms](https://wonder.cdc.gov/datause.html).

- For Japan, download file kind `1` using the manifest IDs. Name the original CSVs `jp-table2-YEAR.csv` and `jp-table43-YEAR.csv`. The staging command checks the pinned bytes, compares the two official tables and writes the UTF-8 normalized extract and vintage-specific residence contract into a new output directory.
- For the US, save the two original grouped TSVs with their query notes and totals. With eLinks, use File > Save as on the result. Name the files `us-wonder-state.tsv` and `us-wonder-national.tsv`. Compare the digests with your acquisition receipt and record the query date.
- For US annual controls, transcribe directly from the published residence tables into `year,location_id,births,report_url,residence_table`, using two-digit Census FIPS, the exact manifest URLs and the listed table numbers. For national monthly controls use `year,month,births,report_url`, `01`–`12`, and the manifest supplement URLs. Keep these inputs independent of WONDER.
- Write normalized UTF-8 extracts with `year,month,location_id,births,male,female` for Japan and `year,month,location_id,births` for the US. Use four-digit years and `annual` for a published annual count. The validators reconcile on location and period keys and require complete grids.

```sh
mkdir -p data/processed/natality
python3 -B scripts/stage_japan_natality.py data/raw/natality data/processed/natality/japan-release
python3 -B scripts/check_natality.py japan data/processed/natality/japan-release/japan.csv \
  --japan-residence-contract data/processed/natality/japan-release/japan-residence-contract.csv \
  --confirm-japan-control-scope
python3 -B scripts/stage_us_natality.py \
  data/raw/natality/us-wonder-state.tsv \
  data/raw/natality/us-wonder-national.tsv data/processed/natality/us.csv
python3 -B scripts/check_natality.py us data/processed/natality/us.csv \
  --us-annual-controls data/processed/natality/us-annual-controls.csv \
  --us-national-month-controls data/processed/natality/us-national-month-controls.csv
python3 -B -m unittest discover -s scripts -p 'test_*.py'
julia --startup-file=no --project=. scripts/check_setup.jl
```

The Python fixtures use synthetic counts for parser and validation failure cases, including reallocations that preserve annual or national totals. The Julia command checks package loading. Keep provider files, session-free exports, transcriptions, processed CSVs and run logs outside Git.
